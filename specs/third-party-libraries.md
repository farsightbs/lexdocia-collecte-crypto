## How to read the table

- **Scope**: `prod` = shipped to consumers (browser portal, PieceMaster); `dev` = tooling, never shipped.
- **V. used**: version in `package-lock.json`. Maintained with `node scripts/check-licenses.mjs --fix`.
- **Ext. audit**: `Yes`, `Partial`, `No` (searched 2026-10-30), or `Not checked` (not security-critical). Links in [External audits](#external-audits).
- **CI version/vuln check**: whether a known-vulnerability check covers the library (see [CI coverage](#ci-coverage)).
- **Commercial use blocked** / **Forced publication**: assessed for our usage (code bundled into a hosted web app and a desktop app).

## CI coverage

- `npm audit --omit=dev --audit-level=high`: every push/PR to `main` and weekly (Monday 06:00 UTC), job `audit` in `security.yml`.
- Dependabot: weekly npm (dev tooling grouped) and GitHub Actions updates.
- CodeQL and gitleaks in the same workflow.
- `scripts/check-licenses.mjs`: license policy, drift against the snapshot, inventory freshness.
- Dev-only dependencies are not covered by `--omit=dev` audit (Dependabot only): accepted, they are not shipped.
